# Motiondex

Organizes your After Effects projects. Downloads and updates only, no source code here.

## Install (or update)

Open **Terminal** (⌘ Space, type `Terminal`, press Return), paste this line and press Return:

```bash
curl -fsSL https://raw.githubusercontent.com/mohaemedwally/motiondex-releases/main/install.sh | bash
```

It downloads the newest Motiondex into Applications and opens it. No "can't be opened" warning.
It may ask for your Mac password (you won't see it as you type).

Once it's installed, Motiondex updates itself.

Or download the `.dmg` from the newest release: [Releases](https://github.com/mohaemedwally/motiondex-releases/releases/latest).
